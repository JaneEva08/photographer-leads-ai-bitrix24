# Контекст для Claude Code

Учебный кейс интенсива «Первая ИИ-услуга для бизнеса» и карточка портфолио: ИИ-разбор заявок частного фотографа в РФ. ТЗ — `TZ.md`.

## Что сделано
- Этапы 1–4 ТЗ: каркас FastAPI + страница, провайдер GigaChat, правила (прайс, календарь, needs_human), анонимизатор с журналом, клиент Битрикс24 (лид, задача, уведомление).
- Живой прогон 23.10.2026 на настоящих GigaChat и Битрикс24: 6 тестовых заявок прогнаны, результаты и найденные расхождения в `TEST_PROTOCOL.md`.
- Калькулятор клиента (`/`, 3 шага: расчёт → проверка → отправлено) и панель пересчёта с персональной скидкой у фотографа (`/admin`). Скидки: будний день −10 %, ранняя бронь свадьбы −5 %, потолок 15 %, персональная до 30 % только в /admin. Сценарии К1–К8 пройдены на живом Битрикс24 через API; визуальную часть страницы глазами не проверяли.
- Исправлено после разбора и живого прогона: исходный текст заявки в лид, сбой ИИ не теряет заявку калькулятора, фильтр цен/дат/обещаний в черновике, дата собирается кодом из частей (число, месяц, день недели), шаблонные ответы для жалоб и нецелевых заявок, пароль `ADMIN_PASSWORD` на `/admin`, блокирующие вызовы вынесены в потоки, расширен анонимизатор (фамилии и отчества, имена родственников, паспорт, карта), `APP_TODAY` для фиксации «сегодня».
- Мониторинг (ДЗ VPe05, 24.10.2026): `app/loki.py` — отправка логов в Loki фоновым потоком, бизнес-события через `log_event`; стек Loki + Grafana с автоподключением дашборда в `monitoring/`. В события — только категории и числа, без ПДн.
- `pytest` — 142 теста зелёные; тесты изолированы от настоящего `.env` (`tests/conftest.py`).

## Что осталось
1. Нет лимита запросов на публичный калькулятор (на сервере поставить rate limit, например в Nginx).
2. Нет проверки дублей лидов по телефону (`crm.duplicate.findbycomm`).
3. GigaChat иногда обрывает JSON и пропускает поля: скрыто запасными значениями, но тексты тогда общие. Если нужно лучше — менять параметры или модель.
4. Анонимизатор на правилах и словаре: редкое имя вне контекста («зовут», «сын», «дочка») может пройти. Рассмотреть NER.
5. Одно имя в разных падежах получает разные метки (осознанный компромисс: иначе при обратной подстановке теряется падеж).
6. Округление скидки вверх до сотни (−10 % от 6 300 даёт −700, а не −630): при желании округлять к ближайшим 100.
7. Визуально проверить калькулятор в браузере (цвет строки скидки, клик по датам, мобильная плашка).

## Окружение
- `.env` заполняется по `.env.example`; сертификат НУЦ Минцифры — в `certs/` (не в git). Вебхук Битрикс24 с правами `crm`, `task`, `im`; право на пользователей не обязательно: при ошибке `user.current` ID берётся из `profile`.
- `DEMO_MODE=true` — только для показа (виден блок «Что ушло в нейросеть»), в обычной работе `false`.
- `APP_TODAY=ГГГГ-ММ-ДД` фиксирует «сегодня» для демо и протокола; пусто — настоящая дата.

## Правила проекта
- Только синтетические данные. Ключи — только в `.env`, не выводить в логи и чат.
- Дату и цену считает код (`app/rules.py`, функция `quote`; дата — `pipeline.resolve_shoot_date`), не нейросеть и не браузер. Не переносить эту логику в промпт или JS.
- Тон ответа для жалоб и нецелевых заявок задаёт шаблон (`pipeline.template_body`), а не модель.
- Журнал анонимизации не должен содержать исходных значений.
- В Loki — только категории и числа: не передавать в `log_event` текст заявки, имена, контакты, id лида как метку. Метки Loki — только `app`, `env`, `level`, `event`.
- Ручные сценарии — только на настоящем GigaChat, заглушки только в автотестах.
- После изменений — `pytest`.
